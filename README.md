# Dyn-3D

Project page for **Dyn-3D: Unveiling and Resolving Ego-Motion Ambiguity in Vision-Language Models**.

The page presents the Dyn-3D benchmark, the TempoVista framework, and Kinematic-GSPO.

## Local Preview

Open `index.html` in a browser, or serve the directory with any static file server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Assets

Figures are copied from the InkMind paper source:

- `static/images/teaser.jpg` — Figure 1 (Kinematic Collapse and Dyn-3D)
- `static/images/method.png` — TempoVista pipeline
- `static/pdf/paper.pdf` — paper PDF
